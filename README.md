# AFK Idle RPG

**방치형 RPG. 캐릭터가 알아서 탑을 오르고 몬스터를 때려잡아요. 장비 모으고 합성해서 더 강해지고, 환생하면 영구 보너스! 자라는 재미 + 오프라인 수확의 기쁨.**

Unity C# 기반, DI Container + Event-driven 아키텍처.

## Links
- 🌐 **Play Demo**: https://kongnamul-muchim.github.io/AFK/

## Tech Stack
- Unity 6 (C#)
- DI Container
- SOLID Principles
- Event-driven Architecture
- Rebirth / Prestige System

## AI 활용

AI 코딩 에이전트를 UI 스캐폴딩과 반복 코드 작성에 사용했습니다.
작업 규칙(네이밍·계층 구조·금지 API)은 `AGENTS.md`에 명시해 두고 진행했습니다.
