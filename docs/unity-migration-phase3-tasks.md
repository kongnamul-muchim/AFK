## 📝 메모

- **UI Toolkit vs uGUI**: UI Toolkit이 반응형 레이아웃에 유리하지만, 레거시 에셋 호환성은 uGUI가 나음
- **인벤토리 가상화**: 아이템이 많을 경우 `ListView`의 가상화 기능 활용 (성능 최적화)
- **애니메이션**: Animator Controller보다 Animation Clip 직접 제어在某些 경우 간단할 수 있음
- **입력 시스템**: Unity의 새 Input System 사용 권장 (구 Input Manager보다 유연)
- **성능**: UI Toolkit은 uGUI보다 런타임 오버헤드가 약간 높을 수 있으므로 프로파일링 필수
