## 왜 (Why)

바쁜 현대인들을 위해 최소한의 조작으로도 즐길 수 있는 방치형 RPG 게임이 필요합니다. 2D 사이드뷰 시점에서 탑을 오르며 전투하고, 사용자가 적극적으로 플레이하지 않아도 자동으로 캐릭터가 성장하고, 로그아웃 중에도 진행이 저장되는 경험을 제공합니다.

**프로토타입 목표:**
- 상용화 가능한 코드 구조와 품질로 프로토타입 제작
- **Unity 독립 아키텍처**: 게임 로직은 100% 순수 JavaScript, Unity 는 렌더링/입력만 담당
- 서버 연동은 제외 (로컬 스토리지 기반)
- 향후 서버 연동, 과금, 광고, Unity 이식 등 확장 가능한 아키텍처 설계

## 변경 사항 (What Changes)

- **2D 사이드뷰 탑 오르기**: 캐릭터가 자동으로 탑을 오르며 몬스터와 전투
- **자동 전투 시스템**: 캐릭터가 자동으로 몬스터와 전투를 수행
- **오프라인 진행**: 로그아웃 중에도 게임 시간이 경과하며 보상 획득
- **스탯포인트 성장 시스템**: 레벨업 시 스탯포인트 획득, 사용자가 직접 분배
- **컬렉션 인벤토리**: 중복 아이템은 카운트로 관리, 합성으로 다음 등급 장비 획득
- **자동 반복 진행**: 보스에게 패배 시 이전 스테이지에서 자동 진행
- **튜토리얼 시스템**: 첫 실행 가이드, 단계별 미션
- **사운드 시스템**: BGM, SFX, 음량 조절
- **설정 시스템**: 사운드, 진동, 데이터 관리
- **로딩 화면**: 로고, 리소스 로딩, 버전 표시
- **상용화 준비 구조**: 모듈화, 설정 분리, 로깅, 오류 처리

## 기능 (Capabilities)

### 신규 기능

- `combat`: 자동 전투 시스템 - 몬스터 자동 타겟팅, 스킬 사용, 전투 로그
- `progression`: 캐릭터 성장 - 레벨업, 경험치, 스탯포인트 획득 및 분배
- `inventory`: 컬렉션 인벤토리 - 중복 아이템 카운트, 장비 합성 시스템
- `offline-rewards`: 오프라인 보상 - 로그아웃 시간 계산, 보상 지급
- `stage`: 탑 스테이지 시스템 - 10 층 단위 보스, 패배 시 자동 반복
- `ui-hud`: 2D 사이드뷰 게임 UI - 캐릭터/몬스터 표시, 상태창, 인벤토리 화면
- `config`: 게임 설정 관리 - 밸런스 값, 확률, 상수 분리
- `storage`: 데이터 저장/로드 - 로컬 스토리지, 마이그레이션 지원
- `tutorial`: 튜토리얼 시스템 - 첫 실행 가이드, 단계별 미션
- `audio`: 사운드 시스템 - BGM, SFX, 음량 조절 (Unity 독립)
- `settings`: 설정 시스템 - 사운드, 진동, 데이터 관리
- `loading`: 로딩 화면 - 로고, 리소스 로딩, 버전 표시
- `data-management`: 데이터 관리 - CSV 기반 아이템/몬스터/밸런스 데이터

## 영향 (Impact)

- **프로젝트**: 신규 웹 기반 2D 방치형 RPG 게임 (탑 오르기) - 프로토타입
- **기술 스택**: Vanilla JavaScript (ES6+) + HTML5 Canvas
- **Unity 연동**: 게임 로직 레이어와 Unity 래퍼 레이어 분리 (Unity 의존성 제로)
- **데이터 관리**: CSV 기반 (아이템, 몬스터, 밸런스) - Excel 로 편집 가능
- **저장소**: 로컬 스토리지 (향후 서버 연동 확장 가능)
- **외부 의존성**: 없음 (단일 프로젝트)
- **제외 항목 (프로토타입)**: 
  - 서버 연동 및 회원제
  - 과금 시스템
  - 광고 연동
  - 소셜 기능

## 아키텍처 원칙 (Unity 독립)

```
┌─────────────────────────────────────────────────────┐
│  Unity Layer (View/Input)                           │
│  - Unity MonoBehaviour (렌더링, 입력, 오디오 출력)  │
│  - JavaScript ↔ Unity 브릿지                        │
├─────────────────────────────────────────────────────┤
│  Game Logic Layer (100% Pure JavaScript)            │
│  - 게임 상태, 전투, 성장, 인벤토리, 스테이지 로직   │
│  - Unity 의존성 없음 (웹/네이티브 이식 가능)        │
├─────────────────────────────────────────────────────┤
│  Core Layer                                         │
│  - 이벤트 버스, 스토리지, 설정, 로거                │
└─────────────────────────────────────────────────────┘
```

**핵심 원칙:**
1. 게임 로직은 Unity API 를 직접 호출하지 않음
2. Unity 래퍼는 게임 로직 상태를 구독해서 렌더링만 담당
3. 입력은 Unity → 이벤트 → 게임 로직 흐름
4. 나중에 웹/네이티브로 이식 시 Unity Layer 만 교체
5. 모든 게임 데이터는 CSV 로 관리 (Excel 로 편집 가능)

## CSV 데이터 관리

### 관리할 데이터
| CSV 파일 | 내용 |
|---------|------|
| `items.csv` | 아이템 데이터 (ID, 이름, 등급, 타입, 옵션, 값) |
| `monsters.csv` | 몬스터 데이터 (ID, 이름, 레벨, 스탯, 보상) |
| `skills.csv` | 스킬 데이터 (ID, 이름, 쿨다운, 효과) |
| `stages.csv` | 스테이지 데이터 (층수, 난이도, 보스 여부) |
| `achievements.csv` | 업적 데이터 (ID, 조건, 보상) |
| `tutorial.csv` | 튜토리얼 데이터 (단계, 조건, 가이드) |
| `audio_definitions.csv` | 사운드 ID 매핑 |
| `game_config.csv` | 밸런스 설정값 |

### CSV 장점
- **Excel/Google Sheets 로 편집 가능**: 밸런스 조정이 쉬움
- **버전 관리**: git 으로 변경 사항 추적
- **파싱 간단**: JavaScript 라이브러리minimal 의존
- **상용화 준비**: 라이브 Ops 툴 연동 용이
