# AFK Idle RPG — 게임 기획 문서 (GDD)

> 장르: 방치형 RPG
> 엔진: Unity 6 + Vanilla JS (WebGL)
> 제작 기간: 6주 (2026-03-27 ~ 2026-05-07)

---

## 1. 게임 개요

- 장르: 방치형(RPG) + 클리커
- 플랫폼: Web (HTML5 Canvas)
- 핵심 재미: 자동 전투를 보면서 장비를 수집/합성하고 스테이지를 돌파
- 타겟 유저: 짧은 시간에 성장하는 재미를 원하는 캐주얼 게이머

---

## 2. 핵심 루프

1. 몬스터 자동 사냥
2. 아이템 드롭 획득
3. 아이템 합성으로 더 좋은 장비 제작
4. 스테이지 클리어 → 더 어려운 스테이지 도전
5. 레벨업 + 스탯 투자로 캐릭터 성장
6. 일정 구간마다 환생해서 더 강하게 재시작

---

## 3. 캐릭터 시스템

### 3.1 기본 스탯

| 스탯 | 설명 | 초기값 |
|------|------|--------|
| HP | 체력 | 100 |
| ATK | 공격력 | 5 |
| DEF | 방어력 | 2 |
| VIT | 체력 스탯 | 1 (HP 10당 1) |
| STR | 힘 스탯 | 1 (ATK 2당 1) |
| DEX | 민첩 스탯 | 1 (치명타 0.5%당 1) |

### 3.2 레벨업

- 레벨 1→2 필요 경험치: 100
- 레벨당 필요 경험치 증가율: 1.2배
- 레벨업 시 스탯 포인트 1개 획득
- 스탯은 VIT/STR/DEX 중 선택해서 투자

### 3.3 전투 스탯 계산식

- 최종 ATK = 기본 ATK + 무기 ATK + (STR × 2)
- 최종 DEF = 기본 DEF + 방어구 DEF + (VIT × 0.5)
- 최종 HP = 기본 HP + 장신구 HP + (VIT × 10)
- 치명타 확률 = 5% + (DEX × 0.5%)
- 치명타 데미지 = 150% (기본)

---

## 4. 전투 시스템

### 4.1 기본 구조

- 100ms 간격으로 자동 공격
- 플레이어와 몬스터가 번갈아 공격하는 방식 아님
- 플레이어가 계속 공격하고 몬스터가 반격하는 구조
- 전투 중 플레이어 조작 불필요 (완전 자동)

### 4.2 데미지 계산

- 데미지 = ATK - DEF (최소 1 보장)
- 치명타 발생 시: 데미지 × 1.5
- 크리티컬 기본 확률: 5%

### 4.3 몬스터

- 스테이지당 10마리 몬스터 등장
- 몬스터는 스테이지가 올라갈수록 체력/공격력 증가
- 10스테이지마다 보스 등장 (고블린왕 → 에인션트 드래곤 → 월드이터)
- 몬스터 스탯 증가율: 1.1배 (스테이지당)

---

## 5. 스테이지 구조

### 5.1 진행 방식

- 총 30스테이지 (기획 기준)
- 각 스테이지: 10마리 몬스터 연속 전투
- 10/20스테이지: 보스 스테이지 (몬스터 1마리 but 강력)
- 스테이지 클리어 시 다음 스테이지 해금
- 전멸 시 가장 최근 클리어한 스테이지에서 재시작

### 5.2 난이도 곡선

| 스테이지 구간 | 난이도 계수 | 특징 |
|-------------|------------|------|
| 1~9 | 1.0~1.9 | 초반 성장 구간 |
| 10 (보스) | 2.0 | 첫 보스, 고블린왕 |
| 11~19 | 2.1~2.9 | 중반 성장 구간 |
| 20 (보스) | 3.5 | 두번째 보스, 에인션트 드래곤 |
| 21~29 | 3.6~4.4 | 후반 성장 구간 |
| 30 (보스) | 5.0 | 최종 보스, 월드이터 |

## 6. 아이템/장비 시스템

### 6.1 장비 종류

4종 장비 슬롯, 각각 다른 스탯 담당

| 부위 | 주요 스탯 | 아이템 개수 |
|------|----------|-----------|
| 무기 (Weapon) | ATK 보너스 | 25단계 (1001~1025) |
| 갑옷 (Armor) | DEF 보너스 | 25단계 (2001~2025) |
| 신발 (Boots) | 이동속도 | 25단계 (3001~3025) |
| 장신구 (Accessory) | HP 보너스 | 25단계 (4001~4025) |

### 6.2 등급 체계

5개 소재 등급 × 5개 희귀도 등급 = 25단계

**소재 등급 (grade 1~25):**
- 1~5: Bronze (청동)
- 6~10: Iron (철)
- 11~15: Steel (강철)
- 16~20: Gold (금)
- 21~25: Mythril (미스릴)

**희귀도 (rarity):**
- Common (60% 드롭)
- Rare (30% 드롭)
- Epic (9% 드롭)
- Legendary (1% 드롭)
- Mythic (0% 드롭, 합성 전용)

### 6.3 스탯 성장 예시 (무기)

| 등급 | Common | Rare | Epic | Legendary | Mythic |
|------|--------|------|------|-----------|--------|
| Bronze (1) | ATK+2 | ATK+4 | ATK+6 | ATK+8 | ATK+10 |
| Iron (6) | ATK+14 | ATK+18 | ATK+22 | ATK+26 | ATK+30 |
| Steel (11) | ATK+38 | ATK+46 | ATK+54 | ATK+62 | ATK+70 |
| Gold (16) | ATK+86 | ATK+102 | ATK+118 | ATK+134 | ATK+150 |
| Mythril (21) | ATK+182 | ATK+214 | ATK+246 | ATK+278 | ATK+310 |

## 7. 합성 시스템

### 7.1 기본 규칙

- 같은 아이템 5개 → 한 등급 높은 아이템 1개
- 베이스 아이템 전환: rusty → iron → steel → gold → mythril
- 타입(무기/갑옷/신발/장신구)은 유지됨
- 합성 성공률: 100% (실패 없음)

### 7.2 합성 예시

```
bronze_sword(common) × 5개 → bronze_sword(rare) 1개
bronze_sword(rare) × 5개 → bronze_sword(epic) 1개
...
bronze_sword(mythic) × 5개 → iron_sword(common) 1개
```

### 7.3 최대 등급

| 타입 | 최대 grade |
|------|-----------|
| 무기 | 25 (Mythril Mythic) |
| 갑옷 | 25 |
| 신발 | 25 |
| 장신구 | 25 |

## 8. 환생 시스템

- 일정 스테이지 도달 시 환생 가능
- 환생 시: 레벨/아이템 초기화
- 환생 시 유지되는 것: 영구 보너스 스탯, 도감 기록
- 환생할수록 더 빠른 성장 가능

|------|--------|--------|

## 11. CSV 데이터 파이프라인

### 11.1 파일 구성

| 파일 | 내용 |
|------|------|
| items.csv | 아이템 100종 데이터 (ID/이름/등급/타입/희귀도/스탯) |
| monsters.csv | 몬스터 20종 데이터 (HP/ATK/스테이지/보상) |
| stages.csv | 스테이지 30개 데이터 (난이도/몬스터수/보상배수) |
| game_config.csv | 게임 밸런스 설정 (전투/인벤토리/오프라인/플레이어) |
| audio_definitions.csv | 오디오 리소스 정의 |
| tutorial.csv | 튜토리얼 데이터 |

### 11.2 CSV 설계 의도

- CSV 수정만으로 밸런스 조정 가능
- 코드 재컴파일 불필요
- 기획자가 직접 데이터 수정 가능

## 12. 일일 미션

- 일일 미션 5개 제공
- 미션 예시: "몬스터 100마리 처치", "골드 1000 획득"
- 완료 시 보석 보상
- 매일 자정 초기화

---

## 13. 주요 UI 화면

### 13.1 메인 전투 화면

- 상단: 레벨/HP/경험치바/골드/보석
- 중앙: 전투 필드 (플레이어 캐릭터 + 몬스터)
- 하단: 스탯/인벤토리/합성/던전 메뉴 버튼

### 13.2 인벤토리

- 4개 탭 (무기/갑옷/신발/장신구)
- 1행 5열 그리드 레이아웃
- 상단에 현재 장착 장비 표시
- 무한 스크롤

### 13.3 합성 화면

- 현재 보유 아이템 리스트
- 합성 가능한 아이템 하이라이트
- 합성 버튼 + 결과물 미리보기
