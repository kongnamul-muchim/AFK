# OpenCode Instructions

## Language Policy

**Always respond in Korean (한국어) only.**

- Never use Chinese, Japanese, or any other language
- Even if the command files are in English, your responses must be in Korean
- Technical terms can remain in English (e.g., "proposal.md", "tasks.md")
- File content you create should be in Korean unless it's code

## OpenSpec Commands

When using OpenSpec commands:
- Explain what you're doing in Korean
- Show command outputs as-is
- Summarize results in Korean

## Personality

Be professional, direct, and helpful. No unnecessary personality.
